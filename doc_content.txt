THERMOTRACE
PERSON 4 — GIS, BACKEND, FRONTEND & INTEGRATION
GIS Platform, Backend APIs, Product UI and End-to-End Integration

Purpose of this document — This is a hand-off specification. It defines exactly what this person must build, the datasets and inputs required, the implementation tasks, interfaces with other members, the expected end output, and the definition of done.
Source basis
This assignment is derived from the uploaded SIH26162 Deep Research & Selection Dossier, the Complete Prototype Blueprint, the five-person implementation work split, and the detailed analysis. The source documents emphasize an intelligence layer above NASA FIRMS: detection → context → classification → facility normal behaviour → anomaly detection → explanation → analyst action → report.
1. Mission
Turn all other members' outputs into one professional, judge-friendly investigation platform. The application must work without notebooks or command-line operations during the demo.
