# Pilot 001 Handoff Verification Checklist

This checklist must be used manually by the project lead when distributing assignments to human reviewers.

- [ ] Reviewer received their assigned CSV
- [ ] Reviewer can open/edit it
- [ ] Reviewer can access required evidence sources (imagery, maps, FIRMS, etc.)
- [ ] Reviewer understands the six permitted labels
- [ ] Reviewer understands the strict difference between `Unknown` and `Incomplete`
- [ ] Reviewer understands evidence requirements and formatting
- [ ] Reviewer understands the absolute requirement for independent review
- [ ] Reviewer knows exactly where and how to return the completed file

Upon Return:
- [ ] Completed file received with expected filename
- [ ] Completed file passes automated structural validation script
